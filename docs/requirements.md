# Requirements - User Stories

1. As a new PhD student, I want to reference data sources, so that I know where our data comes from
2. As a new PhD student, I want to reference data collection methods, so that I know how to collect data
3. As a new PhD student, I want to reference analysis methods, so that I understand what analysis method(s) I should be using
4. As a new PhD student, I want to reference publication venues, so that I know where to publish my work
5. As a new PhD student, I want to find the information I need easily, so that I can begin contributing to my research group as soon as possible
